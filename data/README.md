# data/

Real site map for SiteSense: Cittadella Universitaria, Catania (OSM way 231201634).

| File | What |
|---|---|
| `site.json` | Site definition (hand-written); `mapFile` points to the map. |
| `map.geojson` | Site map in the SiteSense map format, generated by `build_map.py`. |
| `osm/cittadella.osm.gz` | Saved OpenStreetMap extract (input of the script). |
| `build_map.py` | Converts the extract to `map.geojson` and checks the map rules. |

## Re-run

```
python3 data/build_map.py             # convert the saved extract (offline, reproducible)
python3 data/build_map.py --download  # fetch a fresh extract from the OSM API first
```

Python 3.9+, standard library only. The script exits with code 1 if a map rule fails.
Without `--download` the output is byte-identical on every run.

## Mapping

OSM tags to areas, paths, entrances and assembly points, with the rules for each map rule, are in
[docs/plans/SS-18-osm-map.md](../docs/plans/SS-18-osm-map.md).

## Known limits

- `slopePercent` is 0 for almost all paths: OSM has no elevation (only numeric `incline=…%` is used).
- Crossings between paths on different layers, bridges or tunnels are not joined by a shared vertex.
- Areas outside the perimeter, overlapping areas and multipolygon relations are dropped (the script prints counts).
